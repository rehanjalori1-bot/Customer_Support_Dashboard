# Financial & Operations Analytics Dashboards (Excel)

This repository contains production-grade Excel analytics systems designed for Customer Support SLA tracking, Retail Sales performance, and Finance Operations (AP/AR Working Capital & Aging Schedules).

## 📁 Repository Contents
* `Dashboard_1_Customer_Support.xlsx` - Ticket SLA, CSAT diagnostics, and volume tracking.
* `Dashboard_2_Retail_Sales.xlsx` - Revenue, profit margin trends, and XLOOKUP/INDEX+MATCH benchmarking.
* `Dashboard_3_Finance_Operations.xlsx` - Unified AP/AR schema, aging schedules (1–30, 31–60, 90+ days), and disputed balance tracking.
* `Reference_Guide.pdf` - Complete formula audit trail, data transformation steps, and schema documentation.
